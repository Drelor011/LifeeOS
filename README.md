# LifeOS

Персональная операционная система для жизни: задачи, календарь, привычки и статистика в одном минималистичном интерфейсе.

Чистый HTML, CSS и JavaScript. Без фреймворков, библиотек и сборки. Все данные хранятся в браузере, сервер не нужен.

## Возможности

- **Главная.** Количество задач, количество выполненных и общий прогресс.
- **Задачи.** Добавление, отметка выполнения, удаление.
- **Календарь.** Месячный вид, переключение месяцев, события на любую дату, подсветка сегодняшнего дня.
- **Привычки.** Карточки с ежедневной отметкой, серия дней подряд (streak) и лента за последние 7 дней.
- **Статистика.** Всего выполнено задач, процент выполнения, самая длинная серия привычек, график привычек за неделю и рейтинг серий.
- **Тёмная и светлая тема.** Переключатель в боковом меню (на телефоне в правом верхнем углу).
- **Русский и английский.** Переключается без перезагрузки страницы.
- **Адаптивность.** На телефоне боковое меню превращается в нижнюю панель.

## Запуск

Сборка не нужна.

1. Скачайте папку проекта.
2. Откройте `index.html` в браузере.

Файлы `index.html`, `style.css` и `script.js` должны лежать в одной папке.

### Публикация на GitHub Pages

1. Загрузите три файла в репозиторий.
2. Откройте **Settings → Pages**.
3. В разделе **Source** выберите **Deploy from a branch**, ветку `main` и папку `/ (root)`.
4. Через минуту сайт появится по адресу `https://<ваш-логин>.github.io/<репозиторий>/`.

Если после обновления файлов на телефоне видна старая версия, увеличьте число в `style.css?v=3` и `script.js?v=3` в `index.html` или очистите кэш браузера.

## Структура проекта

```
LifeOS/
├── index.html   разметка всех страниц
├── style.css    стили, тёмная и светлая темы
└── script.js    логика приложения
```

Код в `script.js` разбит на нумерованные блоки: утилиты, даты, язык и тема, состояние, помощники UI, навигация, затем по блоку на каждый раздел.

Поток данных простой: действие пользователя меняет объект `state`, затем `commit()` сохраняет его в LocalStorage и перерисовывает интерфейс.

## Хранение данных

Всё хранится в LocalStorage браузера:

| Ключ | Что хранит |
|---|---|
| `lifeos:v1` | Задачи, привычки и события календаря |
| `lifeos:theme` | Выбранная тема: `dark` или `light` |
| `lifeos:lang` | Выбранный язык: `ru` или `en` |

Формат данных:

```js
task  = { id, text, done }
habit = { id, name, days: ["2026-11-16", ...] }   // даты выполнения
event = { id, date: "2026-11-16", text }
```

Важно знать:

- Данные привязаны к браузеру и устройству. Между телефоном и компьютером они не синхронизируются.
- Очистка данных сайта или режим инкогнито приведут к потере данных.
- Перед очисткой можно сохранить данные: в консоли браузера выполните `localStorage.getItem("lifeos:v1")` и скопируйте результат.

## Темы

Все цвета заданы переменными в начале `style.css`. Светлая тема переопределяет их в блоке `:root[data-theme="light"]`. Чтобы изменить цветовую схему, достаточно поправить значения переменных, например `--accent` и `--grad`.

## Языки

Переводы лежат в объекте `I18N` в `script.js`. Тексты в разметке помечены атрибутами `data-i18n`, `data-i18n-placeholder`, `data-i18n-aria`, `data-i18n-title`. Тексты, которые строит JavaScript, берутся через функцию `t("ключ")`. Склонения («1 день, 2 дня, 5 дней») обрабатывает `Intl.PluralRules`.

Чтобы добавить язык:

1. Добавьте объект с переводами в `I18N` по образцу `ru` и `en`, включая поле `locale`.
2. Добавьте код языка в массив `LANGS`.
3. Доработайте обработчик кнопки языка: сейчас он переключает только между русским и английским.

## Технологии и требования

- HTML5, CSS3 (переменные, Grid, Flexbox, анимации), ванильный JavaScript (ES2020).
- Современный браузер: Chrome, Safari, Firefox, Edge последних версий.
- Шрифт Inter подгружается с Google Fonts. Без интернета подставляется системный шрифт, и всё продолжает работать.
